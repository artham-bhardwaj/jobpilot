Job sources

Each source is one company board or a fixed list of career pages. JobPilot reads only the public postings you configure; it doesn't crawl the web and can't see every job. Check each site's terms before adding it. Requests are rate-limited ({{ settings.http_min_interval_seconds }}s per host), size-capped, robots.txt is {{ "respected" if settings.respect_robots_txt else "NOT checked (disabled in .env)" }}, and private network addresses are refused.

A job expires only after its source omits it in consecutive successful runs. Outages, rate limits, malformed responses and empty or collapsed listings never expire jobs. Dry run fetches and shows what would change without saving anything (it still contacts the site).
