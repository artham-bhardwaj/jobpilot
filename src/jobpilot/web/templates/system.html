Scheduled tasks

Run manually here, or enable them under Settings → scheduler. They run only while your computer is on: either with JOBPILOT_SCHEDULER_ENABLED=true (inside jobpilot serve, currently {{ "on" if settings.scheduler_enabled else "off" }}) or via the systemd user timer (jobpilot scheduler systemd). Nothing runs while the computer is asleep or off; overdue tasks run on the next pass. When offline, collection records sources as "unavailable" and expires nothing. Scheduled tasks never send email or submit applications.
